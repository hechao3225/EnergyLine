# 能量管道乐园 · 第一章《失落乐园》美术素材包 v1.0

## 内容与用途

本包根据已确认的三个关键9:20界面（乐园主页 / 6×6解谜 / 设施复苏）制作，统一深蓝紫梦幻星空、暖金金属、浅紫拼图瓷砖、青蓝能量光效、云海与浮空乐园的视觉风格。

- `00_reference/`：三张历史UI设计参考图（不能直接拆成游戏按钮或场景层）
- `01_scenes/`：9:20场景背景、同一座乐园的场景母图；场景母图是矩形插画，不是建筑逐层PSD
- `02_characters/`：星芽、波铃、云绒透明PNG立绘及小表情素材
- `03_facilities/`：旋转木马、摩天轮、城堡、入口门的broken/restoring/active状态素材
- `04_puzzle_tiles/`：256×256规则化透明背景棋盘元件，包含powered/idle两态；`board_6x6_900.png`严格为6×6
- `05_ui_components/`：无文字按钮底图、卡片和进度条；建议在React中动态叠加文本/图标
- `06_icons_and_fx/`：图标及透明能量/庆典光效
- `07_previews/`：使用独立素材拼合的页面示例（仅供核验层级/色彩）
- `08_source_atlases/`：生成源图总表，用于挑选后续需精修的图块

## 技术说明

图像均为PNG，独立角色/设施和棋盘元件具有alpha透明通道。管道元件绘制采用统一中心点、端口对齐，允许代码旋转90度；但源/目标与关卡机关是否可旋转仍取决于游戏逻辑。

注意：本素材包是**第一轮可用于原型/UI拼装的独立PNG资产**，并非完整量产美术（没有可编辑的PSD/分层源文件）。源AI总表的部分小尺寸设施素材放大后仍需人工精修；角色透明抠图含边缘辉光，建议在目标平台实机检查暗色/亮色背景。

没有修改EnergyLine仓库、游戏代码或99关数据。

## 设施高清补充
旋转木马的三个状态从同一张高清主体提取，避免位置漂移；此版本的“荒废/修复中”采用明度和饱和度的视觉区分，正式破损细节仍需后续精修。其他设施三状态目前来自小尺寸原画集，放大仅用于UI原型，请勿直接视作最终量产大图。
