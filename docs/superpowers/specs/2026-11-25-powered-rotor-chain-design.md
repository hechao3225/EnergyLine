# 双动力转盘连锁实验关

## 目标

在 R1 已验证单转盘教学和手感的基础上，验证“一台机关改变下一台的供能条件”是否成立。

## 关卡规则

- 关卡代码为 `R2`，标题为“动力转盘 · 机关带动机关”。
- 关卡包含 A、B 两台动力转盘。
- 玩家先接通 A。
- A 的环轨换位后，下路管线接上 B 的供能口。
- B 在本次操作中自动通电并启动。
- A、B 的环轨动画依次播放，不能同时重叠。
- B 的环轨把一扇断开的能量闸送到目标线路。
- 玩家最后扳通能量闸，点亮设施。

最优操作为 2 步：

1. 旋转 A 的供能直管。
2. 扳通换位后的能量闸。

## 动画

- `activatePoweredRotors` 返回按启动顺序排列的换位步骤。
- 每一步包含该转盘启动前后的完整盘面。
- 棋盘一次只播放一台转盘的环轨换位。
- 当前步骤结束后，棋盘使用该步骤的目标盘面启动下一台转盘。
- 全部步骤结束后恢复最终真实盘面。

## 验证

- A 首次通电后，连锁启动 B，启动顺序固定为 A→B。
- 两段换位动画各包含 8 个移动管道。
- A 动画的环轨提示位于上侧，B 动画的环轨提示位于下侧。
- 双转盘全部换位后目标仍为 `0/1`。
- 能量闸保持断开，扳通后设施全部点亮。
