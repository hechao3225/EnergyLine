# 乐园宇宙主题重构设计（第一轮）

日期：2026-11-12
状态：已确认（用户批准「按推荐」）
范围：H5 版；小游戏/安卓稳定性另开批次。

## 1. 目标

把「能量管道乐园」从单一乐园主线升级为「乐园中心 + 10 个主题区」的乐园宇宙。第一轮只换世界观、文案、收集物、成就与入口，**不改玩法**。

## 3. 世界观

星河坠落后，乐园的能量网络断了。你是新上任的**乐园修复师**，从乐园中心出发，用可旋转的能量管道把星光接回每一处设施；修复设施、点亮区域、吸引游客，最终把乐园扩展成由多个主题区组成的「乐园宇宙」。

能量体系底层只有一套导通规则；区域只是不同叫法与配色：星光（中心）、气流（云上）、生长能量（植物园）、海流（海底）、光/记忆（星空、放映厅）、机械动力（玩具工坊、机械动物园）、梦境能量（梦境游乐场）、庆典能量（节日岛）。

目标口径：单关接通一处设施 → 设施恢复运转；一区全部设施恢复 → 解锁下一主题区；全游戏「修复 99 处乐园设施，点亮整座乐园宇宙」。

## 6. 内容模型

```text
src/content/
  world.ts        // 世界观、角色、能量体系
  zones.ts        // 11 个 ZoneDef + 5 个中心分区
  glossary.ts     // 旧词→新词、禁用词
  levels.ts       // 99 条 LevelContent
  collection.ts   // 99 条 CollectionEntry
  index.ts        // 选择器
src/types/content.ts
```

- `LevelConfig` 增加 `zoneId?`，文本字段改为可选；`defaultLevels.ts` 只保留布局/par。
- 选择器：`getZone`、`getZoneForLevel`、`getLevelContent`、`getCollectionEntry`、`getZoneProgress`、`getCenterDistricts`。
- 自定义/无尽关卡无内容时回退到 `level.title/hintText` 或通用文案。

## 7. 内容规则

- 99 关标题：`{设施}·{状态}`，唯一；标题 ≤12 字，提示 ≤45 字。
- 99 关提示必须提到本关实际机制：能量闸/单向阀/十字/固定管道/多源。
- 99 件藏品：12 类 `artKey`（carousel/wheel/fountain/arch/lamp/stage/balloon/train/aquarium/telescope/toy/clock），名字唯一，1–2 句 lore。
- 14 个成就 ID 不变，文案乐园化；修正 5/10 关判定与重复刷同一关的连续完美计数。
- 现有 12 个花素材保留给后续魔法植物园，不用于中心图鉴。

## 8. 验收

- 主题审计 0 命中；99 条内容/藏品、14 成就、11 区域齐全。
- 布局哈希不变；`solve-min-par` 99/99；`test_circuits`/`test_park_progress` 通过。
- 旧存档的已通关、最佳步数、星级、货币、成就保留。
- 首页/选关/关卡/胜利/图鉴/成就/规则/无尽/工坊全部使用新文案；世界地图显示 11 区，中心可玩、其余「即将开放」。
- 不做：新玩法、新卫星关卡、小游戏同步、安卓稳定性修复。
