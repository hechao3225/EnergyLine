# 假能源头复活（2026-11-22）

> 上一轮双源体检（[DUAL-SOURCE-AUDIT](DUAL-SOURCE-AUDIT-2026-11-22.md)）发现 **14 关有 18 个能源头一盏灯都点不亮**，是纯装饰。
> 这一轮把假头全部接活：**99 关 0 死源**，其中 10 关是“一个真头 + 一个差一盏的假主干”，2 关做成“两个源都能通关、但步数不同”。

## 1. 配方与结果

补丁集中在 `scripts/decoy-revives.ts`（显式配方表 + 生成期验收），由 5 个 `chapter*-gen.ts` 在 `applyLevelRepairs` 之后统一调用。

| 关 | 处理 | 复活结果 |

| L5 | 补 4 格斜向支路 | 近失 2/3（Δ12） |
| L10 | 补 5 格 | 近失 1/2（Δ14） |

| L30 | 补 3 格 | **双全解**（Δ3，两源都能通关） |

（Δ = 先走假支路、再改用真源补齐全亮，比 par 多花的步数。）

## 2. 生成期验收

`decoy-revives.ts` 对每个补丁跑三条断言，不满足就让生成器直接报错：

1. `solveRuleLevel` 的 par 必须等于关卡数据（不许把最少步数改便宜）；
2. 开局必须 0 盏点亮（不许白送）；
3. 每个能源头单独都必须能点亮至少一盏（不许再有纯装饰头）。

## 5. 后续

- **L30 / L33 是第一批「次优双解」**：两个源都能通关，但一条多 3～6 步。需要玩家视角试玩，确认“两条都能通、一条更贵”读得出来。
- **部分近失诱饵 Δ 偏大**（L10 Δ14、L52 Δ16、L5 Δ12）：支路太长，玩家可能两下就放弃，可以再缩短 1～2 格。
- **L59 变成单源关**：这颗头怎么接都会把主路 par 从 17 打到 11～14，暂时删掉；如果坚持双头，得重排主路而不是补支路。
