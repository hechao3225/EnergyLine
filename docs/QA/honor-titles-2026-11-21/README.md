# 荣誉称号档案验收

日期：2026-11-21
视口：390×844、360×800

## 玩家路径

1. 首页点击星芽头像。
2. 打开“修复师档案”。
3. 查看并切换荣誉称号。
4. 切换到“成就”页查看实时进度。
5. 关闭档案后，已查看的称号红点消失。

## 通过项

- 首页没有新增荣誉墙图标，头像仍是唯一入口。
- 有未查看称号时，星芽头像显示红点。
- 称号墙展示 12 个称号、解锁状态和当前佩戴状态。
- 已解锁称号可以点击佩戴，并写入本地进度。
- 成就页按成长、技艺、效率和无尽挑战分组。
- 关联称号显示在成就卡中，进度条和文字完整显示。
- 360×800 与 390×844 下称号卡无内容溢出。
