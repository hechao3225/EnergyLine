# 乐园修复图鉴验收

日期：2026-11-21
视口：390×844、360×800

## 玩家路径

1. 从首页进入“关卡”路线。
2. 每个已解锁节点直接显示对应设施藏品。
3. 点击节点查看设施名称、故事、关卡标题和最佳步数。
4. 已修复设施可以再次挑战，未修复设施可以开始修复。
5. 首页不再提供独立“乐园图鉴”入口。

## 通过项

- 关卡路线与设施藏品使用同一份关卡数据。
- 已修复节点显示彩色藏品，未修复节点显示剪影。
- 节点保留关卡编号、当前关高亮和星级。
- 设施详情在路线内展开，不进入第二层弹窗。
- 详情按钮能够进入所选关卡。
- 390×844 与 360×800 下路线和详情面板均在可视区域内。
