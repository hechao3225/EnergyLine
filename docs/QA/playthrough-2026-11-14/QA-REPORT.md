## 阻断级

### 1. 存档异常直接白屏，且永远无法自恢复

`readParkProgress()` 对 `energy_park_progress_v2` 做裸 `JSON.parse`，无 try/catch；应用也没有 ErrorBoundary 或「重置存档」入口。

复现（两步都能稳定白屏）：

1. `localStorage.energy_park_progress_v2 = "{bad json"` → 刷新，`#root` 子节点为 0，页面全白。
2. `localStorage.energy_park_progress_v2 = "{}"` → 刷新，同样白屏（`coins/hints/rewardedLevels` 缺失，读取即抛错）。

证据：`screens/15-corrupt-save-white-screen.png`，控制台为 `useState → ...` 的 React 崩溃栈。

影响：无论是一次写入中断、用户清理浏览器数据到一半，还是**将来给进度加字段而不迁移老存档**，老玩家都会永久进不来（刷新也救不回来，只能手动清站点数据）。

### 2. 关卡工坊可以发布「不可能通关」的关卡

编辑器中电池与设施完全没有管路连接时，`进入试玩` 依旧生效，给出 30 步、目标 0/1 的死局。没有连通性校验，也没有「无法接通」的提示。

## 体验与设计

### 数值/经济

1. **钻石只进不出。** 首次通关 +10/关（99 关共 990），商店只有「50 金币 → 1 个提示灯泡」，钻石没有任何消耗入口，也不会用于复活/跳过。证据：`screens/11-shop.png`。
2. **重玩已通关关卡，结算显示「修复奖励 +0 +0 +0」**，同时底部写「再玩一次，挑战更高星级」——四星已满时这句话本身不成立。证据：`screens/06-victory-replay-zero-reward.png`。
3. **99 关全部默认解锁**，从首页两次点击即可跳到第 99 关，主线推进没有任何节奏保护或引导。
4. 每日任务奖励 100 金币，与首次通关 100 金币同价；金币唯一的出口是 50/个的提示灯泡，长期看金币同样会溢出。

### 提示系统

5. **提示只是模板文案**，不是可执行解法。99 条提示由「闸要扳通·单向阀看箭头·十字管不用转·固定管道不能转·多源分片接·先主干后支路」这类短语拼装而成，后期关卡最长的提示就是上面这一串，只是末尾换成设施名。卡住时基本帮不上忙，却要扣 1 个灯泡。
6. **无尽挑战 / 工坊试玩里点提示同样扣灯泡**，只弹一句通用文案（`useHint` 不区分模式）。
7. **步数归零后提示按钮仍可点**，此时棋盘已不接受操作，灯泡纯浪费。

### 操作与手感

8. **能量闸角标语义反直觉且过小。** 断开时角标显示「开」、接通时显示「关」；规则文案用的却是「通/断」，aria-label 又是「开启/关闭」。三种说法互相打架，玩家看到「开」会以为已通电（实际是断路）。触摸区实测 **25×23 px**，紧贴在 55 px 的旋转按钮旁边，误触即白扣一步。证据：`screens/07-level-21-switch.png`。
9. **十字管旋转不改变接法，却照常扣 1 步**（规则里自己写明「四向对称，旋转不会改变接法」）。这是纯粹的分数陷阱：第 4 关实测点击后步数 15→14、rotation 0°→90°、通电状态不变。
10. **「重置」没有二次确认**，并且和「提示」并排，一次误点就清空整局操作。
11. **撤销次数（3 次）用尽后，步数耗尽的弹窗仍在说「撤销上一步，或重新规划通路」**，但此时「撤销一步」是禁用的，只剩「重新挑战」。证据：`screens/04-out-of-steps.png`。

### 信息与视觉

12. **第 1 关 36 格里有 30 格是空的**，但空格照样渲染成带星光的紫色卡片，看起来完全可点（实际 disabled）。全作 3564 格里 1408 格为空（39.5%），空盘视觉噪音偏大。证据：`screens/02-level-01.png`。
13. **顶部四星是「按当前步数预估的星级」**，开局就是 4 颗实心星，随步数递减；和「已获得星级」语义混在一起，容易被读成已满星。同一行里「步数 12」是剩余步数，底部「操作足迹 · 0 步」是已用步数，两个「步数」方向相反。
14. **能量源美术是一枚金色圆币 + 星星**，和金币图标几乎同款；未点亮的设施是灰暗剪影，在紫色底板上更像禁用物而不是目标。证据：`screens/08-endless.png`、`screens/03-level-02.png`。
15. **首页进度条旁的礼物按钮** aria-label 是「查看进度奖励」，点开却是每日任务；左侧四个纯图标入口（来信 / 宇宙 / 任务 / 图鉴）没有文字，且「图鉴」复用了钻石图标，与货币图标撞脸。证据：`screens/01-home.png`。
16. **关卡预览左右箭头只有 23 px 宽**，几乎贴着卡片边缘，命中率低。
17. **无尽挑战没有任何「第几关 / 连胜」反馈**（内部有 `streak`，界面不展示），结算也不显示连击；关卡标题只写「无尽挑战」，引导卡退化成「接通能量管道 / 修复设施！」。
18. 首页导航在玩法页不存在；图鉴/成就/来信/宇宙 只能从首页图标进入，玩法中途无法查看。

## 建议修复顺序

1. 存档容错：`readParkProgress` 加 try/catch + 默认值合并 + 版本迁移；外层补 ErrorBoundary；设置页加「重置存档」。这是唯一会让玩家永久进不去的问题。
2. 能量闸：角标改为「通/断」并与规则文案统一，触摸区至少 44×44，或整格长按切换。
3. 结算文案：重玩不再显示 3 个 +0；满星时把「挑战更高星级」换成「再修一次」或直接隐藏。
4. 给钻石一个出口（兑换提示 / 皮肤 / 跳过），否则去掉钻石只留金币。
5. 工坊进入试玩前做连通性校验，不通过时明确提示「电池与设施未接通」。
6. 十字管与「已对齐」限制：或不计步，或点击时给「无需旋转」的轻提示，不扣步。
7. 关卡 1 收紧盘面（或空格改为更弱的分隔样式），降低空盘噪音。
8. 无尽挑战补「第 N 关 / 连胜 N」并显示在 HUD。
