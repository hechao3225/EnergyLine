# 动力转盘实验关验收

## 入口

首页实验场顶部显示“机关 R1 · 通电变形”。入口完整落在手机视口内，没有遮挡“继续修复”、设施轮播、进度条或底部导航。

![首页入口](01-home-rotor-entry-390x844.png)

## 初始盘面

- 两盏设施，初始目标 `0/2`。
- 动力转盘显示青绿色机关标识和 3×3 环轨。
- 底部说明为“动力转盘通电后，周围 8 格管道会沿环轨换位”。

![初始盘面](02-rotor-initial-390x844.png)

## 首次教学

第一次进入动力转盘实验关时，自动展示三步教学：

1. 旋转供能管道，接通中央转盘。
2. 周围 8 格管道沿环轨顺时针移动一格。
3. 管道朝向不变，继续接通剩余设施。

教学卡完整落在 390×844 与 360×800 视口内，按钮可正常关闭。

![动力转盘教学](02b-rotor-lesson-390x844.png)

## 启动换位

点击左侧直管后：

- 转盘标识变为金色已启动状态。
- 8 格管道沿方形环轨平滑滑动一格，管道自身朝向保持不变。
- 环轨显示“环轨换位”，轨道同步高亮。
- 原先位于上方的能量闸移动到右上，仍保持断开。
- 右侧设施点亮，目标变为 `1/2`，剩余 5 步。

支持系统震动的设备只在启动瞬间收到 18ms 的轻触感。关闭设置中的“触感反馈”后不会触发；页面不额外抖动，保持上一版稳定的棋盘观感。

![启动换位](03-rotor-spinning-390x844.png)

## 通关

扳通换位后的能量闸：

- 顶部设施点亮，目标达到 `2/2`。
- 两指定操作完成关卡，与 2 步最少步数一致。

![通关结果](04-rotor-victory-390x844.png)

## R2 双转盘连锁

首页实验场新增“机关 R2 · 双机关”。

![R2 初始盘面](06-r2-chain-initial-390x844.png)

点击上方供能直管后：

1. A 转盘先启动，移动上层环轨。
2. 换位后的管线接通 B 转盘，B 转盘继续启动。
3. 两段动画依次播放，环轨提示跟随当前启动的转盘。
4. 动画结束后两台转盘均为已启动状态，目标仍为 `0/1`。

![A 转盘换位](07-r2-chain-a-390x844.png)

![B 转盘换位](08-r2-chain-b-390x844.png)

最后扳通换位到右侧的能量闸，设施点亮并完成关卡。

![R2 通关](09-r2-chain-victory-390x844.png)
