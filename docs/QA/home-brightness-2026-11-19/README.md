# 首页「亮色太多」诊断与改法 · 2026-11-19

对象：`park-shell` 首页（能量管道乐园），390×844 @2x，真实 Chrome 渲染。

## 1. 量化结论

| 版本 | 平均亮度 | 亮度>75% 像素 | 亮度>85% 像素 | 平均彩度 | 高亮+高彩像素 |
| --- | --- | --- | --- | --- | --- |
| 现状 | 52.7% | 24.2% | 13.2% | 40.9% | 5.0% |
| ① 隐藏实验场 | 54.8% | 25.1% | 13.4% | 42.9% | 5.4% |
| ② ① + 降金 | 54.2% | 24.5% | 12.9% | 38.9% | 3.4% |
| ③ ② + 压光（推荐） | 47.8% | 14.7% | 5.3% | 34.1% | 1.1% |

关键发现：**首页的问题不是「平均太亮」，而是「没有亮度层级 + 金色通胀 + 调试面板噪声」**。

- 各区域平均亮度全部挤在 52–62：底栏 62.2、主按钮 61.3、进度条 58.9、关卡卡 54.4、岛插画 53.7、侧栏 52.4 —— 没有主次，眼睛没有落点；
- 金色像素占整屏 8.6%，其中侧栏 18.3%、底栏 16.4%、logo 13.8%、关卡卡 9.0%、岛插画 9.6%；金色本应是「奖励色」，现在用在 10+ 处；
- 首页右半屏被 23 个「实验场」调试入口占据（14 个红色「新」徽章），约 17% 屏幕面积，不是正式玩法内容；
- 亮部面积大：插画（粉树/金城堡/青瀑布）+ 底部粉云 + 星星闪烁，三者叠加。

注：单独隐藏实验场（①）**不会**降低亮度，反而因为暗色面板原本遮住了亮插画，数值还上升；必须先做压光或降金，再隐藏面板。

## 2. 建议的「光阶」（唯一最重要的原则）

| 层 | 元素 | 目标亮度 | 彩度 |
| --- | --- | --- | --- |
| L0 | 背景、云、星点 | ≤ 30% | ≤ 25% |
| L1 | 卡片、面板、未选中页签 | 35–45% | ≤ 35% |
| L2 | 主插画、角色 | 50–58% | 随画 |
| L3 | 唯一主按钮「开始修复」 | 60–68% | 金，唯一满饱和 |
| text | 正文/数字 | 85–95% | ≤ 10% |

现状是 nav 62 / CTA 61 / progress 59 / cards 54 / island 54 / icons 52：所有层级挤成一团。

## 3. 落地顺序（按性价比）

1. **实验场入口移到调试参数**：`import.meta.env.DEV || ?lab=1` 才渲染。零美术成本，去掉 23 个按钮 + 14 个红点；
2. **压光**：`.park-stage::after` 径向暗角（中心透明、边缘 -40%）；`.park-island { filter: brightness(.9) saturate(.8) }`；`.park-home-friends img { filter: brightness(.93) saturate(.85) }`；`.park-nav { filter: brightness(.9) }`；
3. **降金**：侧栏圆钮与底栏图标 `filter: saturate(.6) brightness(.96)`（保留色相识别，别降到灰度）；关卡卡 `saturate(.6)`；进度条改深紫底 + 细金线；logo 去掉洋红外发光、`saturate(.85)`；
4. **金色预算**：只留「开始修复」和资源数字为满饱和金；其余金元素降到 60–70% 彩度；
5. **长期**：侧栏 4 个圆钮、底栏 5 个图标重出一套「米白瓷片 + 金描边」素材，可从根上解决金色通胀；星星闪烁粒子减半。

## 4. 可验收指标

- 整屏：平均亮度 ≤ 48%，亮度>75% 像素 ≤ 15%，平均彩度 ≤ 35%，高亮+高彩 ≤ 1.5%；
- 同时「开始修复」仍是画面最亮的可点元素，插画仍是视觉主体；
- 截图对照：`01-default.png` → `04-dimmed.png`。

## 5. 与已有 `?theme=calm` 的关系

仓库已有 `src/theme-calm.css`（`?theme=calm` 开启，缺省不生效）：它把背景/舞台/棋盘/弹窗压暗，实测整屏 43.1% / 彩度 30.6%，方向正确；但**没有覆盖首页的岛插画、金色侧栏/底栏、logo、实验场面板**，所以首页仍有「亮色太多」的观感。
建议：把 calm 设为默认（或做成「柔光/鲜艳」开关并默认柔光），再补上本文第 3 节的 5 条首页规则。

## 6. 复现

本文四个版本的样式是在浏览器里注入 CSS 预览的（未改任何源文件）：

```js
// ① 去噪
.park-lab-entries{display:none!important}
// ② 降金（在 ① 之上）
.park-side-actions .park-round{filter:saturate(.6) brightness(.96)}
.park-nav .park-icon{filter:saturate(.6) brightness(.98)}
.park-facility{filter:saturate(.6) brightness(.95)}
.park-progress-track{background:linear-gradient(#4a3a6e,#33254f)}
// ③ 压光（在 ② 之上）
.park-stage::after{content:"";position:absolute;inset:0;pointer-events:none;z-index:3;background:radial-gradient(ellipse at 50% 34%,rgba(8,6,20,0) 42%,rgba(8,6,20,.42) 100%)}
.park-island{filter:brightness(.9) saturate(.8)}
.park-nav{filter:brightness(.9)}
```
