## 第二版改了什么

第一版 44–50 是**随机生长**出来的迷宫：盘面铺满、几十个格子乱缠、轴组散落，
和 41–43 的“主干 + 支路 + 一串轴”完全不是一种语言。

第二版改成**手工排布的主干式布局**（`scripts/axis-maps.ts`）：

- 左边一个泉眼，一条横向主干，2–5 条竖直支路；
- 支路尽头才是设施（设施必须落在叶子，否则会截断电流）；
- 轴组是主干上或支路上的**连续 2–3 格**，和 41–43 的“一串轴”同构；
- 难度靠三件事抬：轴组数量（2→4）、设施数量（4→5）、par（11→17）；
- 盘面稀疏（14–18 个格子），和 41–43 一致。

编译器 `scripts/generate-axis-trial.ts` 会：由参数建格 → 邻接推管道类型/朝向 →
分配点击数命中目标 par → 用 `axis-solver` 精确求解复核 → 断言“按解回放能点亮”。

```
41:6  42:5  43:4  44:11  45:12  46:13  47:14  48:16  49:17  50:17
```

## 看什么

1. **44**：两根轴，主干上并排两格 + 支路一格，和 41 关同一种读法，但要多算一路。
2. **47 / 48**：轴开始跨“主干 + 支路”，改一处会同时动两段。
3. **50**：四组轴串在一条主干上，一共 5 处设施、18 步预算——试错几乎没有空间。
