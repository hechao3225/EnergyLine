# 顶栏「最少步数」改造 · 2026-11-14

## 改动
- 玩法顶栏最左的四颗星（`getStarsForSteps` 的实时星级预览）替换为「最少步数」chip：
  - 在四星线内（`stepsUsed <= parSteps`）：金色星标 + `最少 N 步`。
  - 超过四星线：星标灰化 + `当前 X 星`（`opacity: .58`），只在掉星时提醒。
- 数据源 `getParSteps(level)`（求解器算出的真实最少点击次数），与四星线完全一致；
  hover/aria 附带三星、二星阈值。
- 星星保留在：关卡选择卡、结算面板、乐园指南（顶栏那份是重复信息）。

## 验证（390×844 / 360×800，真实浏览器截图）
- 第 2 关开局：`最少 12 步 | 步数 18 | 目标 0/2`，状态栏无溢出（scrollWidth == clientWidth）。
- 13 次点击后：`当前 3 星 | 步数 5`，星标灰化。
- chip 最小宽度锁定 25cqw，两种文案切换不引起顶栏跳动。
