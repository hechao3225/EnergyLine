# 宁静配色 A/B 验收

日期：2026-11-19
结论：**通过。** `?theme=calm` 只覆盖颜色、光晕与常驻呼吸动画强度，不改变布局；默认主题仍是当前正式配色。

## 改动范围

- `src/theme-calm.css` 使用 `html[data-theme="calm"]` 隔离主题覆盖。
- `src/main.tsx` 只读取 `?theme=` 查询参数并写入根节点，缺省不设置主题、不改变现有页面。
- 首页、棋盘、弹窗、导航和结算改用低饱和深靛与暖纸阅读区；通电和奖励保留青、金两种状态色。
- 棋盘上的常驻轴环、满电脉冲和目标脉冲改为静态柔光，交互提示仍保留。

## 验证结果

| 项目 | 默认主题 | 宁静主题 |
|---|---|---|
| 390×844 首页/棋盘/结算 | 通过 | 通过 |
| 360×800 首页/棋盘/结算 | 通过 | 通过 |
| 横向溢出 | 0 | 0 |
| 控制台错误 | 0 | 0 |
| 390×844 结算面板尺寸 | `366.6×274.3` | `366.6×274.3` |
| 360×800 结算面板尺寸 | `338.4×232.0` | `338.4×232.0` |

两个主题在相同视口下结算面板位置和尺寸完全一致，说明主题层没有参与布局计算。

## 使用方式

默认访问保持正式主题；需要体验宁静方案时追加：

```text
?theme=calm
```

## 边界

移动端证据来自 Chrome 390×844 与 360×800 触屏仿真；当前环境没有可用 ADB 真机。
