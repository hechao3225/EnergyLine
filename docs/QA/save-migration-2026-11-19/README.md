# 旧存档重塑补偿验收

日期：2026-11-19
结论：**通过。** 旧版通关记录会保留，旧 best/星级按当前盘面重置，并只发放一次重塑补偿。

## 验证结果

| 项目 | 结果 |
|---|---|
| 3 个已通关关卡迁移 | 获得 150 钻石 |
| 连续读取两次 | 余额保持 150，不重复发放 |
| 99 个已通关关卡 | 封顶 4950 钻石 |
| 旧 rewardedLevels | 保留，首通奖励不重复 |
| 390×844 设置页说明 | 可见、无横向溢出 |
| 控制台错误 | 0 |

浏览器验证先写入 `honeycomb_cleared_levels = [1,2,3]`，首次进入显示“钻石 150”，刷新后仍为 150。补偿说明位于 390×844 设置页可见区域，尺寸约 `304×42`。
