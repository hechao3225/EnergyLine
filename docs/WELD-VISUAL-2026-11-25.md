# 焊死关辨识：能量源标记 + 首次教学（2026-11-25）

> 目标：玩家**进关、还没点第一下之前**就知道"本关管道通电即焊死"，而不是焊上之后才看出来。
> 结论：不做逐格标记（钢箍/钢印那版已撤回），改成**关卡级标记：能量源换材质** + **首见教学卡** + **误点兜底提示**。

## 为什么用能量源做标记

- 能量源是"能量从哪来"的唯一信息，进关第一眼就在盘面上，不占用格子、不压管道接缝（接缝是转管解谜最不能挡的信息）。
- 一个标记覆盖所有焊死关，教学只需要教一条对应关系：**钢色能量源 = 本关通电即焊死**。
- 用**材质**（深钢蓝）而不是换色相，避免和双色关"红源/蓝源"抢语义；另外配一枚「焊」钢印做形状冗余，色弱玩家也能认。
- 源色按验收意见定稿为**低亮度、低饱和的深钢蓝**（不要荧光/发光感）：`grayscale(.52) sepia(.55) hue-rotate(192deg) saturate(1.15) brightness(.66) contrast(1.32)` + 很淡的冷光 drop-shadow。
