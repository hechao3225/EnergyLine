## 二、微信小游戏

### 1. 资质（按顺序办，周期最长）

| 事项 | 谁办 | 说明 |
|---|---|---|
| 小游戏类目 | 你 | 后台选「休闲游戏 → 益智」，个人主体可选 |
| **ICP 备案** | 你 | 2023 年起小游戏必须备案，需主体证件、域名/服务器信息；个人可办，约 1–20 个工作日 |
| **软件著作权** | 你 | 微信近年普遍要求；加急 3–5 工作日（代办约 300–1000 元），普通 30+ 天 |
| 实名/防沉迷 | 平台 | 微信宿主侧统一提供，后台按指引开启健康系统 |
| 版号 | 不需要 | 纯广告变现、无内购则不需要版号 |
| 自审自查报告 | 你 | 后台下载模板填写（玩法、内容、付费点） |

### 2. 后台配置

1. 注册小游戏 → 拿到 **AppID**。
2. 填入 `src/config.ts` 的 `CONFIG.wechat.appId`，并同步 `tools/build.mjs` 里 `project.config.json` 的 `appid`。
3. 流量主：累计注册用户 ≥ 1000 后可开通，创建**激励视频**广告位，把 ID 填进 `CONFIG.wechat.rewardedAdUnitId`。
4. 服务器域名：本项目无网络请求，可留空（首次提审会要求说明「无网络请求」）。

### 3. 提审

```bash
npm run build:prod
# 微信开发者工具 → 导入项目 → 选择 build/wechat 目录（AppID 用真实值）
# 工具内「预览」扫码真机验收 → 「上传」→ 后台填版本号 → 提交审核
```

提审信息建议：

- 游戏名称：神树灵泉
- 一句话简介：旋转翡翠水渠，引灵泉活水唤醒神树百花
- 类目：休闲游戏 / 益智
- 截图：至少 3 张（首页天梯、关卡棋盘、通关弹窗）——`minigame/.shots/` 里有现成素材，建议真机重截
- 测试账号：无需（单机无登录）

### 4. 常见驳回点

- 缺 ICP 备案 / 软著 → 补件
- 首页无适龄提示 → 已加
- 隐私政策缺失 → 本项目不收集个人信息，后台声明「不收集」；若后续接排行榜需补隐私协议
- 广告位未配置却展示广告入口 → 当前无广告位时点击直接赠送步数，不会出现空广告

## 三、抖音小游戏

### 1. 资质

| 事项 | 说明 |
|---|---|
| **软件著作权** | **强制**，无软著不能提审。建议立刻办加急 |
| 主体 | 个人可上架；企业主体买量投放更顺 |
| ICP 备案 | 抖音侧按主体要求，通常需要 |
| 版号 | 无内购则不需要 |

### 2. 后台配置

1. 注册抖音小游戏 → 拿 **AppID** → 填入 `CONFIG.douyin.appId` 与 `tools/build.mjs` 的 `project.config.json`。
2. 广告位：开通「穿山甲」激励视频，ID 填 `CONFIG.douyin.rewardedAdUnitId`。
3. 提审：抖音开发者工具导入 `build/douyin` → 真机预览 → 上传 → 提审。

### 3. 抖音差异点（代码已处理）

- 分享：`tt.shareAppMessage` 支持 `channel: 'video'`（录屏分享），当前走默认。
- 录屏：如需「精彩时刻」，要接 `tt.getGameRecorderManager()`，属于二期。
- 侧边栏复访：`tt.navigateToScene({ scene: 'sidebar' })`，可做复访奖励，二期。

## 四、上线后建议（按优先级）

1. **埋点**：现在只有 `platform.log`。建议接微信「小游戏数据助手」的 `wx.reportAnalytics` 打点（进入关卡/通关/流失/广告观看）。
2. **留存**：每日一关 / 连续登录奖励，配合分享拉新。
3. **变现**：激励视频目前只在「步数耗尽」触发，可再加「提示」「跳过难关」两个触点。
4. **二期功能**：无尽模式（H5 已有生成器，逻辑可直接搬）、关卡编辑器、排行榜（需后端 + 隐私协议）。
